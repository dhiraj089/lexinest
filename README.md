# LexiNest – Smart NLP Text Analyzer

A browser-based NLP project (pure HTML + CSS + JavaScript, no install needed).

## How to run
Open `index.html` in any web browser.

## Modules
1. Text Processing – tokenization, filtration, script validation
2. Stop word removal, stemming, lemmatization
3. Bag of Words and N-Grams
4. Part-of-Speech tagging
5. Named Entity Recognition
6. Exploratory Data Analysis (word cloud)
7. WordNet synonyms/antonyms and Brown corpus demo
8. Word Sense Disambiguation using the Lesk algorithm

## How it works
Enter text once at the top; each tab has buttons that run the technique on that text and show the result.
Techniques are rule-based JavaScript re-implementations of the NLTK concepts, using small built-in
dictionaries/corpora for WordNet, Brown and Lesk.
